This is an internal tool that is used to collect donations.
It is continuously deployed and there are thus NO CHANGELOG at this stage.

It is a server-side helper to allow [kiwix-apple](https://github.com/kiwix/kiwix-apple) reader
users to make donations using ApplePay (via Stripe).

We want to support other donation workflows and maybe replace donorbox to regain
some flexibility, increase accountability and remove a US-based third-party.
